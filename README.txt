OUBOC Digital Card
==================

Files:
- index.html
- styles.css
- script.js
- assets/ouboc-logo.png
- assets/favicon.svg

How to use:
1. Open index.html in any modern browser.
2. Update phone, email, website, location and vCard values in index.html and script.js if needed.
3. The page is mobile-first and optimized for iPhone 16 Pro Max, while remaining responsive on smaller and larger screens.
4. The Save Contact button creates and downloads a VCF contact file.

Brand colors used from the supplied identity:
- Orange: #FF7400
- Navy: #0D4A8B
- Sky Blue: #6DB6E8
- Light Neutral: #F2F4F7

Fonts:
- Cairo for Arabic
- Montserrat for English
Both load from Google Fonts with system fallbacks.
